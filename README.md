# Home Planer

Облачная версия для GitHub / Vercel / Supabase подготовлена. Настройка аккаунтов, базы и переменных окружения — в [DEPLOYMENT.md](DEPLOYMENT.md). В облаке проекты доступны владельцу после входа; локальный файловый режим также поддерживается.

Личный 2D-редактор для Windows и домашней сети. Реализованы этапы 1–5. Полный план находится в DEVELOPMENT_PLAN.md. Все панели и геометрия редактируемые; изображение-макет используется только как ориентир.

## Запуск и остановка
Требуется Node.js 22.12+ или 24 LTS. Дважды нажмите `start-local.bat` в `D:\Home Planer`. При первом запуске BAT устанавливает зависимости. Через PowerShell:

```powershell
Set-Location 'D:\Home Planer'
npm install
npm run dev
```

Откройте http://localhost:3000. Сервер слушает 0.0.0.0 и печатает фактические IPv4-адреса адаптеров. Последний запуск: домашний адаптер http://192.168.1.161:3000. Этот адрес может измениться при переподключении; ориентируйтесь на вывод сервера. Телефон должен быть в той же домашней сети. Разрешите Node.js в брандмауэре Windows для частной сети, если Windows спросит. Брандмауэр отключать не нужно. Доступ с физического телефона пока не проверен.

Для остановки нажмите Ctrl+C в окне сервера. Если порт занят, приложение не останавливает чужой процесс. Другой порт:

```powershell
$env:PORT='3001'
npm run dev
```

## Рисование
Выберите участок, дом, гараж, сарай, беседку, другую постройку, внешнюю стену или перегородку в каталоге. На панели над планом задайте форму:
- Прямоугольник: перетащите от первого угла до противоположного.
- Многоугольник: последовательно отмечайте вершины; Enter завершает, щелчок рядом с первой точкой замыкает.
- Стены: отмечайте точки цепочки; Enter завершает открытую цепочку. Выбор прямоугольника или многоугольника при активной категории стен создаёт замкнутые стены.

Внизу рабочей области при построении цепочки можно зафиксировать длину следующего сегмента (м) и угол (градусы). Пустое поле означает выбор курсором. После ввода длины курсор её не меняет. Tab переключает поля. Shift временно задаёт ортогональное направление. Escape отменяет незавершённое построение. Завершённая цепочка — одна команда в истории.

## Размеры и узлы
Выберите объект на плане или в дереве объектов. У участка/постройки отображается площадь по внешнему контуру. У прямоугольника доступны длина, ширина, поворот и опора (первый угол/центр). У свободного контура и стены — длина и угол каждой стороны, опора (начало/конец/центр), координаты узлов. Для стены также доступны толщина, высота, назначение и связь с постройкой.

Числовые поля принимают точку и запятую. Enter или кнопка ↵ подтверждает ввод. Геометрические изменения сначала показываются на плане и в списке затронутых сторон; нажмите «Применить» либо «Отменить изменение». Щелчок на размерной подписи открывает соответствующее поле. Смена единиц м/см/мм не меняет геометрию.

Кнопки «Длина» и «Угол» у стороны фиксируют её текущие параметры. Несовместимое изменение показывает конфликт и блокирует применение, сохраняя исходник. Алгоритм изменяет выбранные опорные узлы и проверяет ограничения; общего численного решателя, автоматически перестраивающего весь контур, пока нет. Другую опору можно выбрать самостоятельно или снять нужные ограничения.

Чтобы независимо менять стороны прямоугольника, преобразуйте его в многоугольник. Узлы можно перетаскивать или менять численно; свободное перетаскивание угла тоже преобразует прямоугольник в многоугольник. Для многоугольника доступны вставка вершины в середину стороны и удаление вершины (минимум три). Самопересечения и нулевые размеры не принимаются.

Общие узлы стен имеют единственные координаты в проекте. При переносе узла обновляются все связанные сегменты. Привязка к узлам действует с допуском в экранных пикселях. Конец новой стены внутри существующей создаёт Т-узел и делит исходную стену. Стену также можно разделить пополам из свойств. Если разделяемая стена имеет ограничения, сначала снимите их. Само пересечение внутренних частей двух стен пока не создаёт общий узел автоматически.

Контур постройки — источник её геометрии. Внешнюю стену можно связать с постройкой, если она использует соседние узлы этого контура (при построении привяжитесь к его вершинам). Независимые внешние стены нельзя назначить постройке, чтобы не получить расходящиеся контуры. Перегородки могут относиться к постройке отдельно. При изменении связанных узлов прямоугольность тоже проверяется.

## Выбор и камера
V — выбор; H — рука. Space+перетаскивание, Ctrl+перетаскивание и средняя кнопка — временная рука. Колесо меняет масштаб около курсора. «Весь план» учитывает отступы вокруг геометрии.

Shift добавляет/убирает объект из выделения. Перетаскивание пустой области выделяет рамкой; перенос группы сохраняет взаимное расположение и общие узлы. Стрелки сдвигают выделение на шаг привязки, Shift увеличивает шаг в десять раз. Alt отключает привязку. Сетка и шаг привязки настраиваются отдельно.

Ctrl+Z / Ctrl+Shift+Z — отмена/повтор; Ctrl+D — копия; Delete — удаление; Ctrl+S — сохранение. Горячие клавиши не действуют при вводе в поля.

## Хранение
Файлы находятся в `data/projects` относительно папки приложения. Автосохранение через 900 мс после команды. Ручное сохранение и статус доступны сверху. Кнопка «Открыть» читает проекты сервера. «Скачать JSON» создаёт переносимую резервную копию. Предыдущая серверная версия — `.json.bak`.

При открытии нового/другого проекта приложение сначала сохраняет текущие изменения; ошибка сохранения останавливает переход. При конфликте ревизий можно загрузить серверную версию или сохранить отдельную копию. Учебный пример сам по себе не сохраняется, пока не изменён или не нажата кнопка сохранения.

Схема второго этапа имеет версию 2. Старые контуры первого этапа автоматически преобразуются в объекты со стабильными ID узлов, без изменения координат и ревизии. Запись обновлённой версии создаёт резервную копию старого файла. После сбоя браузер может восстановить последний локальный кэш; сервер остаётся основным хранилищем.

Не запускайте два сервера на одном каталоге данных: очередь записи действует внутри одного процесса. Приложение предназначено для доверенной домашней сети и не публикуется в интернете.

## Проверка
```powershell
npm run build
npm test
```

Проверяются реальные площади, опоры, поворот, общие узлы, Т-примыкание, конфликты ограничений, история, сохранение/резервная копия/ревизии и перенос старой схемы. В браузере проверены изменение дома 80 → 96 м², отмена/повтор, построение стены 4,2 м, изменение через подпись до 5 м и запрет изменения заблокированной длины.

Реализованы этапы 1–5, включая отдельные слои, импорт, SVG/PNG и сенсорные жесты. Полная таблица проверок находится в VALIDATION.md.

## Сантехника, электрика и дорожки
Выберите предмет в каталоге и щёлкните на плане. V возвращает выбор. В свойствах доступны реальные размеры, координаты центра, поворот, высота установки и назначение постройке. Электрический знак имеет отдельный минимальный размер в px, корпус — размеры в мировых единицах. При размещении выберите «Свободно» или «На стене»; в свойствах можно изменить стену и отступ. Пересечение предметов разрешено с подсказкой.

Для трубы/провода отмечайте точки и нажмите Enter. Длина и угол следующего сегмента задаются на плавающей панели. У предметов показываются совместимые точки подключения; щелчок рядом с точкой создаёт явную связь. При переносе, повороте или изменении размеров предмета связанный конец следует за ним. Alt позволяет поставить свободную точку. Числовые длины, углы и координаты узлов редактируются в свойствах трассы с предварительным просмотром.

Подключить существующую трассу можно через «Подключения концов»: выбрать начало/конец и порт предмета либо узел другой трассы, затем показать и применить подключение. Для Т-примыкания внутри сегмента сначала нажмите «Вставить узел». Соединяются линии одного типа и назначения; простое пересечение линий ничего не соединяет. Закреплённый конец нельзя передвинуть отдельно — отсоедините его или переместите предмет. Диаметр трубы в мм не меняет толщину экранного обозначения. Длина трассы не включает вертикальные участки.

При копировании предметов вместе с трассами их связи переназначаются на копии. Копия трассы без её предмета становится свободной. Удаление предмета отсоединяет трубы/провода, сохраняя координаты концов; отмена восстанавливает подключения. Конфликт заблокированной длины/угла не применяется.

Дорожка по оси строится полилинией: ширина, материал, сегменты и параллельная копия доступны в свойствах. «Контур покрытия» строится замкнутым многоугольником с редактируемыми сторонами. Площадь считается по границам покрытия. У осевой дорожки прямые торцы и угловые стыки со скосами на острых поворотах. Перекрывающий себя контур отклоняется с сообщением; автоматическое объединение перекрытий не выполняется.

Сборка и 47 тестов прошли. В браузере проверены размещение ванны, подключение трубы, поворот 90°, перенос предмета, дорожка 6 + 4 м шириной 1,2 м с площадью 12 м² и повторное открытие связей с сервера. Проверочные файлы: `examples/stage4-validation.json`, `examples/stage4-demo.json`; снимок: `editor-stage4.jpg`. Нагрузки электрики и строительные нормативы приложение не рассчитывает.

## Проёмы и точные команды
Выберите окно или дверь в каталоге, задайте ширину и при необходимости точный отступ, затем щёлкните на стене. Красный предварительный просмотр означает выход за стену или пересечение другого проёма; такое размещение не применяется. В свойствах меняются тип, размеры, начало/конец отсчёта, сторона и петли двери, подоконник окна и стена размещения. Перетаскивание проёма сдвигает его вдоль стены.

Проёмы следуют за переносом и поворотом стены. Копия стены получает собственные копии проёмов. Перенос/копирование/удаление здания включает назначенные стены и проёмы. При удалении зависимостей сначала показывается предварительный просмотр. Слишком короткая стена вызывает конфликт с требуемой длиной; ширина проёма сохраняется.

В «Точных командах» доступны параллельные стены и связные цепочки: расстояние между осями либо чистый просвет с учётом обеих толщин, сторона смещения, толщина копии и копирование проёмов. Для группы доступны поворот, отражение и числовой сдвиг копии. Выравнивание и распределение работают с независимыми объектами и выбранной неподвижной опорой; группа с общими узлами отклоняется, чтобы не разорвать связи.

Кнопка ⚙ открывает виды привязок, допуск в пикселях, угловой шаг и направление относительно выбранной стороны. Допуск сохраняется при изменении масштаба. На плане показываются цель и направляющие; Alt отключает привязки на время жеста. Скрытая геометрия исключается из целей привязки.

Этап 3 проверен сборкой и 34 тестами: связи проёмов, перенос/копирование группы, запрет укорочения, разделение стены, параллельные цепочки, точность привязок на разных масштабах, выравнивание, история и серверное сохранение. В браузере проверены размещение и перенос окна, дверь 0,9 м с отступом 1,2 м, конфликт укорочения, удаление с отменой и параллельная стена с копией двери. Снимки: editor-stage3.jpg и editor-stage3-conflict.jpg.

Проверочный план разработки находится в examples/stage2-validation.json (отдельно от списка пользовательских проектов). Снимки проверки: editor-stage2.jpg, editor-stage2-conflict.jpg и editor-stage2-tablet.jpg.


## Завершение этапа 5

В панели «Слои» доступны 11 категорий с независимой видимостью и блокировкой. У объекта в свойствах можно сменить слой. Скрытые объекты отсутствуют на плане, в выборе рамкой и в привязках; дерево показывает их недоступными. Заблокированный объект можно просмотреть через дерево, но его свойства, удаление и перенос защищены. Защита действует и на косвенные изменения связанных стен, проёмов и коммуникаций. Undo/redo восстанавливает состояние слоёв. Флажок «Привязка к заблокированным слоям» находится в ⚙.

«Импорт JSON» проверяет схему, размеры файла (до 5 МБ), числа, ID, ограничения и связи до открытия. Старые проекты получают слои автоматически. Импорт создаёт отдельный проект с новым ID; исходный файл не перезаписывается. Перед переходом сохраняются изменения текущего проекта. Импортированную копию сохраните кнопкой сверху; при последующем редактировании работает автосохранение.

«SVG / PNG» открывает настройки изображения: выбранные слои, масштаб 3–400 px/м, поля, автоматические или ручные границы в метрах и прозрачный фон. Размеры всех включённых объектов формируются отдельно от выделения редактора. Панели и сетка в экспорт не входят. Максимум — 8192 px на сторону и 32 Мп; уменьшите масштаб для большого участка. Ручные границы намеренно обрезают изображение. Подписи не размещаются автоматически с обходом друг друга; отключайте ненужные категории при подготовке схемы.

На сенсорном экране касание размещает предмет или точку. Один палец перемещает выбранную геометрию; два пальца одновременно перемещают и масштабируют вид. Появление второго пальца отменяет текущий незавершённый перенос. Оставшийся после pinch палец не продолжает редактирование: поднимите оба и начните новый жест. Жесты камеры не записываются в историю. Кнопка ☰ скрывает каталог, свойства на узком экране открываются отдельно. Кнопка ↔ измеряет расстояние между двумя точками без изменения проекта; ? показывает справку.

Сборка и 55 тестов прошли. Полная таблица 18 сценариев и фактические ограничения находятся в [VALIDATION.md](VALIDATION.md). Проверены экраны 1440 × 900 и 820 × 900, импорт старого проекта и реальные SVG/PNG. Физическое сенсорное устройство и доступ с другого устройства по LAN не проверены; на этом ПК оба адреса возвращают HTTP 200.
